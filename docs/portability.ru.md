# Запись о переносимости

[English version](portability.md)

Слова SHA-256 представлены 32-битными битовыми шаблонами `INTEGER`. Сложение переводит операнды в ограниченную 64-битную арифметику `LONGINT`, выполняет сокращение по модулю `2^32` и возвращает результат без signed overflow `INTEGER`. XOR, AND, NOT, вращения, сдвиги, декодирование входа и кодирование дайджеста используют определённые битовые операции `SYSTEM` Ofront+; порядок байтов задаётся явно и не зависит от CPU. Криптографические октеты используют 8-битный `SHORTCHAR` FreeOberon, а не 16-битный `CHAR`.

Код опирается на то, что Ofront+ с `-88` предоставляет 32-битный two's-complement `INTEGER`, 64-битный `LONGINT`, 8-битный `SHORTCHAR`, принимаемый `ORD`/`CHR` в диапазоне `0..255`, и операции `SET` над битовыми шаблонами `INTEGER`. `scripts/test.sh` оставляет включёнными проверки границ, типов, assertions и указателей Ofront+. Тесты проверяют переносы слов, вращения, логические сдвиги, стандартные SHA-векторы, fixtures HMAC/PBKDF2, границы API и 100 000 мутаций парсера.

`SecureRandom` использует файловый API `Platform` FreeOberon для чтения `/dev/urandom` на macOS и Linux. Неполное чтение, ошибки и полностью нулевой результат отклоняются; псевдослучайного fallback нет.
