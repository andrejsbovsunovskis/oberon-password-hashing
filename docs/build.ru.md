# Сборка и тестирование

[English version](build.md)

Зафиксированный диалект исходников — FreeOberon/Oberon-07: Ofront+ запускается с `-s -88 -7w`, как в штатном `fob`. Криптографические C-библиотеки не используются: сгенерированный C — только backend FreeOberon.

Установите FreeOberon, укажите `FREEOBERON_HOME` на его checkout и запустите `./scripts/test.sh`.

Скрипт выбирает `macOS`, `Linux_amd64` или `Linux_aarch64`, переводит модули в порядке зависимостей и связывает тестовые программы с целевым `libOfront.a`. Также подключается целевой `Platform.c` — документированная граница, через которую `platform/SecureRandom.Mod` читает `/dev/urandom`.

Обычные тестовые исполняемые файлы используют `clang -O3 -flto`. `PasswordBytes.c`, содержащий очистку секретных буферов, компилируется отдельно без LTO, чтобы эти записи оставались внешне наблюдаемым вызовом. Дополнительные флаги C-компилятора передаются через `CFLAGS`; например, AddressSanitizer и UndefinedBehaviorSanitizer запускаются так:

```sh
CFLAGS='-O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer' ./scripts/test.sh
```

Скрипт печатает путь и SHA-256 транслятора, а также версию C-компилятора. При изменении toolchain сохраняйте этот вывод вместе с архитектурой хоста. Сейчас проверена macOS arm64; добавляйте платформу в матрицу поддержки только после успешного основного и sanitizer-запуска.

Для проверки всей цепочки штатного сборщика запустите:

```sh
./scripts/test-fob.sh
```

Скрипт копирует исходники, примеры и тесты во временную папку, затем собирает и запускает все девять тестовых программ настоящим `$FREEOBERON_HOME/fob`, включая тест размеров типов и импорт обоих примеров. Флаги и скрипты установленного FreeOberon не меняются. `fob` использует собственную папку `_Build` в checkout FreeOberon и штатные параметры C-компиляции; оптимизированная сборка и санитайзеры остаются отдельной проверкой через `scripts/test.sh`. Не запускайте несколько `fob`-сборок одновременно в одном checkout.

Для своей программы положите `src/*.Mod` и `platform/SecureRandom.Mod` рядом с главным модулем и вызовите:

```sh
"$FREEOBERON_HOME/fob" /short/path/MyProgram.Mod -o /short/path/my-program
```

Байтовые аргументы объявляйте как `ARRAY OF SYSTEM.CHAR8` с импортом `SYSTEM`; 16-битный `CHAR` сначала явно кодируйте в UTF-8. Пути исходников должны быть короче 80 символов из-за внутреннего буфера текущего `fob`. Проверочный скрипт использует короткую папку в `/tmp` независимо от `TMPDIR`.
