# ADR 001: представление слов SHA-256

[English version](001-word-arithmetic.md)

Использовать `INTEGER` как 32-битный битовый шаблон слов SHA. Сложение выполнять через ограниченную 64-битную арифметику `LONGINT`, затем сокращать по модулю `2^32`; побитовые операции и вращения выполнять операциями `SYSTEM` Ofront+. Это исключает signed-overflow арифметику в сгенерированном C и позволяет компилятору выдавать нативные 32-битные инструкции.
