# ADR 002: источник случайной соли

[English version](002-randomness.md)

Использовать `/dev/urandom` через существующий адаптер `Platform` FreeOberon на поддерживаемых Unix-целях. Адаптер требует полного ограниченного чтения, закрывает дескриптор, отклоняет полностью нулевой результат и не имеет fallback.
