# Поддержка и безопасность

[English version](support.md)

Поддерживаемая цель — macOS arm64 с документированной цепочкой FreeOberon/Ofront+. Другие цели могут быть полезны при разработке, но не считаются совместимыми, пока на них не пройдены полный тестовый и sanitizer-запуски.

Проект прошёл самопроверку. О предполагаемой уязвимости сообщайте сопровождающим приватно; не включайте пароли, рабочие записи паролей, соли вместе с пользовательскими данными или выгрузки production-БД. Исправление безопасности должно оценить затронутые записи и описать необходимую миграцию.

Читатель v1 принимает только записи `oberon-pwh$1$pbkdf2-sha256`. Неявного legacy-reader нет. Будущие readers должны выбираться явно, быть ограничены policy и удаляться только через документированное окно миграции.
